# Dajkesa - Discord Bot & Dashboard

This project is a Discord bot with a web-based dashboard for managing tickets, logs, and server configurations.

## Features
- **Ticket System**: Automated ticket creation and management.
- **Web Dashboard**: Pterodactyl-themed interface for administrators.
- **Anti-Invite**: Automated system to prevent invite links.
- **Audit Logs**: Track administrative actions.

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Create a `.env` file based on the environment variables needed.
4. Start the application: `npm start`.
